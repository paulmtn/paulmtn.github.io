Keyboard from Scratch

Fall 2026 · KICAD

Overview

Schematic consisting of the microcontroller, power decoupling capacitors, crystal, reset circuit, ISP header, and USB-C connector

A keyboard works by having all the switches connected as a grid of circuits with diodes to only allow current to go a certain way. When you press a key, the switch latches which completes the circuit and allows the small current to flow through it. The microcontroller will then compare that location on the key matrix to the character map in its read-only memory (ROM), a lookup table that tells the processor the location of each key and what it represents.
